To get **exactly the platform you described**, don't start with Oral Presentation or Quiz first.

Build it in this order:

# PHASE 1 — Recruiter Plans (Mandatory First)

## File

```text
src/components/Dashboard.tsx
```

## Add recruiter plans

Create:

```ts
type RecruiterTier =
  | 'free'
  | 'paid'
  | 'corporate';
```

Store it:

```tsx
const [recruiterTier, setRecruiterTier] =
  useState<RecruiterTier>('free');
```

Later it will come from database.

# PHASE 9 — Corporate Candidate List

Sort:

```ts
applications.sort((a,b)=>{

 if(a.isPreselected && !b.isPreselected)
   return -1;

 if(!a.isPreselected && b.isPreselected)
   return 1;

 return b.aiScore-a.aiScore;
});
```

Result:

```text
⭐ Ahmed
⭐ Sara
⭐ Karim

Fatima
Youcef
Amine
```
